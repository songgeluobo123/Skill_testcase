# 非功能测试设计（性能 / 兼容 / 可靠 / 安全 / 易用）

> **一句话**：功能测试回答「做对了没有」，非功能测试回答「**在差环境下还能不能做对、会不会伤害用户、换个人会不会用**」。
>
> **实证背景**：某项目 745 条用例的 `test_type` 全是功能/异常/边界/权限——性能 1 条、兼容 9 条、可靠 0 条、安全 0 条、易用 0 条。而同一产品的真实缺陷里，断连后数据冒充实时、弱网升级失败、日志打明文密码占了大头。**非功能维度不是锦上添花，是缺陷主产区。**
>
> **与 UI 族的边界**：`ui_case_design.md` 管「界面上长什么样」；本文件管「系统与环境下稳不稳、安不安全、好不好用」。前者测像素与文案，后者测行为与风险。

---

## 一、五特性与 test_type 映射

| 质量特性 | `test_type` | 回答什么 | 典型漏测后果 |
|---|---|---|---|
| 性能 | `性能测试` | 够不够快、撑不撑得住、资源不失控 | 卡顿、超时、内存泄漏 |
| 兼容性 | `兼容测试` | 换机型/系统/分辨率/语言还对不对 | 特定机型崩溃、排版错乱 |
| 可靠性 | `可靠性测试` | 出故障时能不能恢复、数据会不会丢 | 断连丢数据、重复提交 |
| 安全性 | `安全性测试` | 会不会被别人拿到、改掉、绕过 | 越权、明文密码、重放 |
| 易用性 | `易用性测试` | 能不能学会、少走弯路、出错能自救 | 用户找不到入口、错误提示看不懂 |

**代码层落点**：`test_type` 用上表五个值（预审 9c 值域已含）；9d 按组统计覆盖（安全组含 `安全性测试`+`权限测试`）。

## 二、性能测试（`性能测试`）

**生成公式**：`典型操作 + 负载/数据量条件` → `可量化指标（时间/占用/成功率）`。

| 子维度 | 检查清单 | 典型用例形态 |
|---|---|---|
| 响应时间 | 首屏加载 / 页面切换 / 接口响应 / 搜索 | 冷启动至首页可交互应 ≤2 秒（阈值以性能基线为准） |
| 并发 | 登录 / 提交 / 拉列表 | 100 并发持续 5 分钟，错误率 <1%，P99 ≤ 阈值 |
| 资源占用 | 内存 / CPU / 电量 / 存储 | 训练页停留 10 分钟，内存增量 ≤ 阈值且不持续增长 |
| 大数据量 | 长列表 / 海量记录 / 大文件 | 1000 条记录列表滚动帧率不低于 50fps、无白屏 |
| 降级 | 超时 / 限流 / 服务不可用 | 接口超时后 3 秒内给出超时提示并允许重试 |

**写法红线**：
- 指标必须给**数值或明确引用基线**（「≤2 秒」「P99 ≤500ms」「≤50MB」），禁止「流畅」「不卡顿」；
- **阈值未定就写「待性能基线确认」并单列**，不自己编数字（编的阈值比没阈值更糟：判错了还找不到原因）；
- 单条用例只测一个负载条件，不同并发量级拆条。

## 三、兼容性测试（`兼容测试`）

**生成公式**：`固定功能 + 变化的环境维度` → `该环境下功能与展示均正确`。

| 维度 | 枚举方式 | 典型用例 |
|---|---|---|
| 机型/屏幕 | 主流机型 + 最小/最大分辨率 | 1280×800 与 1920×1080 下首页无裁切、无重叠 |
| 系统版本 | 最低支持版本 / 当前主流版本 | Android 10 与 14 下登录流程一致 |
| 横竖屏 | 支持旋转的页面各一条 | 骑行记录页横屏布局无错位 |
| 系统语言 | 中文 / English（+项目要求语种） | 英文环境下全部文案无中文残留 |
| 网络制式 | 4G / 5G / WiFi / 弱网 | 4G↔WiFi 切换时上传不断流 |
| 外设/固件 | 蓝牙外设型号、固件版本梯度 | 新旧两版固件下指令协议均正常 |
| 系统设置 | 深色模式 / 大字号 / 权限关闭 | 系统大字号下文字不截断 |

**红线**：兼容矩阵**成对出题**（同一功能 × 两个环境各一条），不许写成「多机型均正常」一句话；环境组合用正交分析法选代表组合（`test_methods.md` 方法 6），不要全排列。

## 四、可靠性测试（`可靠性测试`）

**生成公式**：`制造故障（断连/超时/中断/异常输入）` → `系统恢复行为 + 数据完整性`。

| 子维度 | 检查清单 | 典型用例 |
|---|---|---|
| 断连恢复 | 蓝牙/网络断开 → 重连 → 数据与状态 | 训练中断连 30 秒重连，计时不断、数据无缺口 |
| 弱网 | 高延迟 / 丢包 / 抖动 | 弱网下提交订单最终成功或明确失败，不产生重复单 |
| 超时与重试 | 接口超时后的重试与幂等 | 超时重试 3 次仅创建 1 条记录 |
| 异常中断 | 断电 / 杀进程 / 来电 / 切后台 | 训练中杀进程重启，已完成数据保留、无错乱 |
| 长时间运行 | 连续使用 / 反复进出 | 连续训练 2 小时无崩溃、无内存溢出 |
| 数据一致性 | 本地缓存 vs 云端 vs 车端 | 断网期间的记录在恢复后补齐且不重复 |
| 资源耗尽 | 存储满 / 权限被收回 | 存储满时提示明确，不静默丢数据 |

**红线**：预期必须含**恢复后状态**与**数据完整性断言**（「重启后记录仍在且条数一致」），不能只写「不崩溃」。

## 五、安全性测试（`安全性测试`）

**生成公式**：`攻击/越权/异常身份` + `操作敏感数据或接口` → `被正确拒绝且不泄露`。

| 子维度 | 检查清单 | 典型用例 |
|---|---|---|
| 认证 | 未登录 / 会话过期 / 伪造 token | 会话失效后调受保护接口应返回未授权，不返回任何业务数据 |
| 授权越权 | 横向（他人数据）/ 纵向（低权限操作高权限） | A 账号用 B 的设备 ID 调接口应拒绝 |
| 敏感信息展示 | 手机号/邮箱脱敏、密码隐藏 | 个人中心手机号显示为 138****8000 |
| 传输与存储 | 明文密码、日志脱敏、本地存储 | 日志与崩溃报告不含明文密码与完整 token |
| 重放与幂等 | 验证码/支付/注册 token 重放 | 同一验证 token 二次提交被拒绝 |
| 输入注入 | 特殊字符 / 超长 / 脚本片段 | 昵称输入 `<script>` 不被执行、按文本原样显示 |
| 频率限制 | 验证码 / 登录失败 / 接口刷取 | 连续错误登录达阈值后账号临时锁定 |

**红线**：安全用例的预期必须写**拒绝的形态**（状态码/提示/不返回数据），不能只写「安全」；**不得在用例里写真实凭据**。

## 六、易用性测试（`易用性测试`）

**生成公式**：`目标任务` → `达成路径的可度量属性（步数/时长/可见性/可恢复性）`。

| 子维度 | 检查清单 | 典型用例 |
|---|---|---|
| 可学习性 | 首次使用能否找到入口 | 新用户从首页 3 步内可达「添加设备」 |
| 操作效率 | 高频操作步数 | 常用功能（开机/暂停）无需超过 2 次点击 |
| 错误可恢复 | 错误提示是否指路 | 表单校验失败时提示具体字段与修改方法，输入不丢失 |
| 一致性 | 同功能同交互 | 所有列表均支持下拉刷新，同类按钮位置一致 |
| 可见性 | 关键状态可见 | 连接中/已连接/离线三态在页面显著位置可辨 |
| 无障碍 | 字号/对比度/触控区 | 系统大字号下按钮文字不截断；触控区 ≥44×44pt |

**红线**：「好用」不是判据——易用性用例必须落在**步数、时长、可见位置、对比度**这类可数/可看的东西上；主观评价类（「体验流畅」）一律不写。

## 七、生成时自检（每个功能点过一遍）

| # | 问题 | 缺失时补什么 |
|---|---|---|
| 1 | 这个功能有耗时/并发/数据量吗？ | 响应时间或资源占用 ≥1 条 |
| 2 | 有没有换机型/系统/分辨率/语言会变的地方？ | 兼容成对对比 ≥1 条 |
| 3 | 用了网络/蓝牙/外部设备吗？断了会怎样？ | 断连恢复 + 数据完整性 ≥1 条 |
| 4 | 涉及账号/权限/敏感数据吗？ | 越权拒绝 + 脱敏展示各 ≥1 条 |
| 5 | 首次用的人能找到入口、出错能自救吗？ | 路径步数或错误提示 ≥1 条 |

**项目级下限**：App / 设备类项目，五大特性**每类至少 1 条**（预审 9d 库级点名）；纯函数库/纯接口项目可豁免性能之外的部分，须在测试计划写明豁免理由。

## 八、与预审闸门的关系

| 闸门 | 管什么 |
|---|---|
| 9c `test_type` 值域 | 五特性类型拼写合法（性能/兼容/可靠性/安全性/易用性测试） |
| **9d 非功能覆盖** | 库级五特性各 ≥1 条，缺类点名（安全组含 `权限测试`） |
| 第 12 项方法一致性 | 非功能用例的 `design_method` 用场景法/等价类/正交，须有落地证据 |
| 第 7 项可判定 | 性能阈值、安全拒绝形态、易用步数都是可判定断言，仍受黑名单约束（「流畅」「不卡顿」照样拒） |
