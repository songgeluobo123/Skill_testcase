# 测试点分析维度与常见功能覆盖清单

Step 3 基于每个功能点产出测试点。测试点描述"怎么测"（操作和验证动作），**不含预期结果**。

---

## 一、测试点分析五维度（每个功能点至少覆盖）

| 层 | 维度 | 覆盖要点 |
|---|---|---|
| 基础层 | 功能正确性验证 | 正常流程、输入输出、界面元素 |
| 核心层 | 业务逻辑深度 | 业务规则、状态机完整性、数据一致性、权限控制 |
| 防御层 | 异常与边界 | 异常流程、边界值、错误恢复、兼容性 |
| 系统层 | 集成与端到端 | 端到端流程、数据流完整性、系统集成点 |
| 拓展层 | 体验与业务价值 | 可用性、性能体验、业务目标支持 |

## 二、四类场景强制配额（每个功能点）

> 只测"顺利路径"是用例最常见的失败模式。每个功能点必须同时具备以下四类，且满足数量配额：

| 场景类 | 要求 | 说明 |
|---|---|---|
| **正常流程** | **≥1 条** | 核心业务链路、用户最高频路径、端到端完整操作链 |
| **异常操作** | **≥3 条**（与边界合计） | 输入合法性、空值、重复提交、流程中断与恢复、服务不可用 |
| **边界条件** | ↑ 同上合计 | 等价类边界值、最大/最小输入、特殊字符、格式边界、超时阈值 |
| **权限校验** | **≥1 条**（模块内必备） | 未登录访问、无权限操作、跨角色访问、越权防护 |

- 配额按**功能点**计，不按模块计；模块级代理检查见 `scripts/prescreen.py` 第 9 项。
- 只有 1 条正向、没有异常/边界的模块，判为场景失衡（`coverage_audit.py` 的 G2 缺口）。
- 权限校验在**无账号体系**的产品（如纯离线固件）可豁免，但须在测试计划中写明豁免理由。

### 权限校验覆盖清单

- **未登录**：直接访问页面 / 调用接口 → 应跳转登录或返回未授权。
- **无权限**：普通角色访问管理功能 → 应提示无权限，且**数据不外泄**。
- **跨角色**：A 角色操作 B 角色的数据（改 ID / 改 token）→ 应拒绝。
- **越权防护**：横向（同角色他人数据）、纵向（低权限提权）两类都要测。
- **权限变更即时性**：回收权限后会话内是否立刻失效（易漏点）。

## 三、常见功能测试点覆盖清单（查漏用）

### 列表页
- **数据展示**：准确性、完整性、空状态处理、格式与样式。
- **分页**：分页控件显示、导航按钮、数据一致性、分页与筛选 / 排序联动。
- **查询 / 筛选**：基础搜索、高级筛选、实时搜索、重置功能。
- **排序**：单列排序、多列排序、排序状态指示器、默认排序规则。
- **列表操作**：行内操作、批量操作、操作项启用 / 禁用条件。

### 表单页
- **输入框校验**：必填项、等价类、边界值、数据类型、特殊字符。
- **下拉框**：选择性与可填性、模糊匹配、二级联动。
- **单选 / 复选框**：独选型、多选型。
- **时间选择**：开始 / 结束时间关系、时间格式化。
- **提交按钮**：回车 / 单击支持、防重复提交、弱网提交、提交后提示、权限校验。
- **业务约束**：业务规则校验、状态依赖校验。

### 导入导出
- **导入**：正常流程、文件格式支持、文件类型异常、文件内容异常、数据格式异常、业务逻辑异常。
- **导出**：正常流程、导出范围、导出内容、资源限制。
- **模板**：模板下载、模板格式、说明 sheet 页。

### 文件上传
- **类型限制**：文件类型白名单、脚本文件拦截、文件内容校验。
- **体积 / 命名**：浏览后删除文件、超大文件处理、命名冲突处理、存储方式验证。
