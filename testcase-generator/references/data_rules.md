# 数据-规则映射库

本文件为 testcase-generator 技能提供**测试数据校验规则库**。生成测试数据时优先遵守本文件中的规则；
其余"硬约束"（优先级划分、质量评分）已分别收敛到 `case_design.md` 与 `quality_standards.md`，避免口径分散。

---

## 数据-规则映射库（示例，可按项目扩展）

生成测试数据时严格遵循以下规则。可把项目真实的字段约束补充进此库。

```json
{
  "手机号":   { "格式": "11 位数字", "前缀": ["138", "139"] },
  "订单金额": { "类型": "number", "范围": "≥ 0.01", "精度": "2 位小数" },
  "用户等级": { "枚举": ["普通", "VIP", "SVIP"] }
}
```

规则要点：

- **手机号**：11 位数字，常见前缀 138/139 等；不得出现 "12345"（长度不足）或含字母。
- **订单金额**：数值型，≥ 0.01，保留 2 位小数；不得出现负数 "-100" 或 0。
- **用户等级**：只能取枚举值 {普通, VIP, SVIP}；不得出现未定义等级。
- **动态关联**：有依赖关系的数据需生成关联链。如"用户 ID = U123" → 订单号 "ORD-U123-xxx"。
- **合法性预校验**：对照系统元数据（如 Swagger 参数规则）。例：用户名长度 3–10 位，
  则过滤 "ab"（2 位）和 "abcdefghijk"（11 位）。

> 扩展方式：把项目的真实字段、格式、范围、枚举补充进上表；用例生成与 `scripts/score_testcases.py`
> 都会据此校验测试数据有效性。
